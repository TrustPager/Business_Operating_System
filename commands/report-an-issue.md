---
description: File a clean bug report or feature request to the platform team without leaving your assistant.
---

Run the **Report an Issue** skill.

Invoke the skill at `skills/report-an-issue/SKILL.md`. Follow it exactly: work out
whether it's a bug or a feature request, gather the few details that make it
actionable (expected vs actual + where, or the use case + outcome), file it with
`create_service_request` with a clear title, a complete description, the right
category and priority, then confirm it's logged and say plainly what happens
next. Keep it short and reassuring.

Run the **Build Social Strategy** skill.

Invoke the skill at `skills/build-social-strategy/SKILL.md`. First pin the ONE
target this strategy serves (more bookings/leads, local authority, a bigger
audience, or more sales): one account and one target per run. Read the brand
brief / voice (`marketing-strategy/<BrandName>/`) and the business shape
(`knowledge/industry-notes.md`) if available, and optionally do keyless web
research (capped, never blocking).

Produce the six-part strategy: platform focus + why, realistic cadence per
platform, 3-4 content pillars each mapped to the target, the content mix, the
one metric to watch, and the first concrete move this week. Positive-only and
outcome-led, no em dashes.

Then point the owner at the execution follow-ons by outcome: the dated calendar
(`plan-my-content`) and the written posts (`write-post-copy`). The branded
visual studio is a future library module, not a dependency.

Run the **Build My Voice** skill.

Invoke the skill at `skills/build-my-voice/SKILL.md` and follow it exactly.

Start with the company voice, written to `marketing-strategy/<BrandName>/voice.md`
(the same file `/build-brand-strategy` and every content app read, so this is the
deeper evidence-grounded version, not a competing one). Offer the personal voice
as a second pass, written to `personal-voice.md`.

Read the owner's real writing first (a file via `markitdown_convert`, or pasted
samples), then run the short "this, not that" lock-in. Ground every trait in a
real sample, never invent their voice. If a `voice.md` already exists, show the
diff before overwriting. Every sample you write is positive, outcome-led, and has
no em dashes.
